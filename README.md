# 2048

单文件网页版 2048，双击 `index.html` 即可玩，无需服务器、无需联网、无第三方依赖。

**在线试玩**：<https://jiaxin304.github.io/game-2048/>

> 更新方式：把新的 `index.html` 传到本仓库（Add file → Upload files）覆盖，GitHub Pages 会自动重新构建，约 1 分钟生效。

## 操作

| 操作 | 方式 |
| --- | --- |
| 移动 | `↑` `↓` `←` `→` / `W` `A` `S` `D` / `H` `J` `K` `L` |
| 手机 | 在棋盘上滑动 |
| 重开 | `R` 或「新游戏」按钮 |
| 撤销 | `Z` 或「撤销」按钮（最多回退 30 步） |
| 静音 | `M` 或「音效」按钮 |

## 特性

- 滑动、合并、新块出现都有动画，支持系统「减少动态效果」设置
- 分数 + 最高分（`localStorage`），刷新页面自动续上当前局面
- 凑出 2048 后可继续挑战更高分；无路可走时给出结算面板
- 键盘、鼠标拖拽、触摸滑动三种输入
- 音效由 WebAudio 实时合成，不需要音频文件
